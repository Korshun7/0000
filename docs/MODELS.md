# Модели и железо (сентябрь 2026)

## Рекомендация

Для русской деловой почты на одном ПК:

**Основной генератор:** Qwen3.5 / Qwen3.8 **27B** Instruct, квант **Q5_K_M** (или Qwen3-32B, если 27B линейки нет в офлайн-поставке).

**Сортировка:** Qwen3-**8B** Instruct Q5_K_M.

**Эмбеддинги:** BGE-M3 (многоязычный, хорошо тянет русский) или Qwen3-Embedding, если поставка из одной семьи проще.

Лицензия Qwen: Apache 2.0 — проще для закрытого контура, чем Llama Community.

## Почему не «просто самую большую»

| Модель | Роль | Комментарий |
| --- | --- | --- |
| Qwen3.5/3.8 27B | Черновики | Лучший практический выбор на 24 ГБ: русский, инструкции, агентные JSON |
| Qwen3-32B | Черновики | Плотная альтернатива, ~19–22 ГБ в Q5 |
| Qwen3-8B / 14B | Классификация | Дёшево и стабильно с GBNF |
| Qwen3-30B-A3B MoE | Опция скорости | Быстрее 32B при том же классе задач, если GGUF стабилен у вас |
| Llama 4 Scout | Не брать по умолчанию | 10M контекста для почты не нужен, ~55 ГБ |
| Gemma 4 31B | Запасной генератор | Сильный, но Qwen обычно лучше на не-английском |
| DeepSeek R1 distill 32B | Не для писем | Thinking раздувает задержку, тон писем хуже |
| GPT-OSS 20B | Запас на 16 ГБ | Если GPU маленький |
| Облачные GPT/Claude | Запрещено ТЗ | |

Ollama как рантайм **не используем** (сеть и телеметрия). Формат весов — **GGUF** в llama.cpp.

## Железо

**200 писем/сутки не требуют 24 ГБ.** Карта нужна модели, которая пишет черновик, а не очереди писем. Зачем так вышло и что урезать: [WHY_RESOURCES.md](WHY_RESOURCES.md).

| Класс | GPU | Что запускать | Качество ответов |
| --- | --- | --- | --- |
| Рекомендуемый | 24 ГБ | 8B + 27B/32B + embedder (по очереди или слоями) | Рабочее для деловой почты |
| Комфортный | 32–48 ГБ | 8B резидентно + 27B резидентно | Нет выгрузки весов |
| Минимум | 16 ГБ | 8B классификатор + 14B/20B черновики | Заметно слабее длинные треды |
| Без GPU | 64 ГБ RAM, llama.cpp CPU | 8B везде | Минуты на черновик, только пилот |

RAM системы: 64 ГБ, чтобы Outlook + OST + SQLite + модель не дрались. Диск: NVMe, OST и `mailvault.db` не на OneDrive.

Контекст сервера: `-c 32768` достаточно. 128k — если есть юридические простыни; медленнее prefill.

## Квантование

- Сортировка: Q5_K_M или Q8_0 (JSON должен быть железным).
- Черновики: Q5_K_M. Q4_K_M допустим, больше « greasy » формулировок.
- Не Q2/Q3 для писем, которые увидит клиент.

Манифест `configs/models.manifest.json`: имя, файл, sha256, контекст, слоты.

## Дообучение

Сначала **не** дообучать. Стиль = Sent Items в RAG + системный промпт.

LoRA на 8B имеет смысл после 4–6 недель, если пользователь правит > половины черновиков. Датасет только локальный, обучение на той же машине или изолированном стенде без сети. Веса LoRA тоже в манифесте.
