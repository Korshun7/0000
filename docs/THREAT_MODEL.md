# Угрозы и контрмеры

| Угроза | Почему реальна | Контрмера |
| --- | --- | --- |
| Утечка писем в облачную LLM | Любой HTTP API | Нет HTTP-клиента у ИИ, WFP DROP, llama без CURL |
| Автоотправка неверного письма | «Ассистент сам ответил» | Код не вызывает MAPI Send; только Draft |
| Галлюцинация обязательств | Модель дописывает суммы и сроки | citations обязательны; UI блокирует accept без цитат; risks[] |
| Подмена GGUF | Вредоносные веса на диске | SHA-256 манифеста, WDAC, каталог Program Files |
| OOM Guard / зависание Outlook | OOM в STA | Extended MAPI sidecar, очередь на диске |
| Смешение тредов | Тема «Re: договор» | ConversationIndex, не subject |
| Скрытый канал через вложения | Модель вставляет URL | Черновик plain text; внешние ссылки только из шаблона подписи |
| Логи на сетевом диске | Админ положил AppData на UNC | Проверка пути при старте; отказ если не локальный NTFS |
| New Outlook | Веб, Graph | Инсталлятор проверяет classic Outlook |
| Пользователь включает «скачать модель» | Удобство ломает air-gap | В UI нет такой кнопки |

Инцидент-процедура: остановить службы MailVault, скопировать `mailvault.db` и журнал аудита, GGUF не вывозить вместе с почтой без необходимости.
