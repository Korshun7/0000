# Максимально простой контур

Полная архитектура MailVault — на потом. Для одного человека и ~200 писем хватает **трёх частей**: Outlook уже стоит, одна модель 8B на `127.0.0.1`, скрипт «выделенное письмо → черновик».

Не ставить: VSTO, C++ MAPI, вторую 27B, RAG, SQLite, Ollama, Docker, WFP на первом шаге.

## Что выкидываем и чем заменяем

| Было в полной схеме | Простой старт |
| --- | --- |
| Extended MAPI sidecar | `pywin32` COM к выделенному письму |
| Панель в Outlook | Скрипт / ярлык, пока письмо выделено |
| 8B + 27B | **только Qwen3-8B** |
| Эмбеддинги и Sent Items | Текущий тред из `GetConversation()` |
| Очередь SQLite | Outlook — источник правды |
| Три варианта + citations UI | Один черновик в папку «Черновики» |
| Автопрогон 200 писем | Сначала одно письмо; пачка — флаг `--inbox` |

Надёжность, которая **остаётся**: модель не в интернете, `Send` в коде нет, человек жмёт «Отправить».

## Железо для этого режима

8B Q5 ≈ 6 ГБ. Подойдёт GPU 8 ГБ или CPU (черновик — десятки секунд / минуты). 24 ГБ не нужны, пока не надо «письмо почти как есть».

## День 1 на Windows

1. Классический Outlook открыт, Cached Exchange, **не** New Outlook.
2. С другой машины (или с флешки) скопировать `llama-server.exe` + `Qwen3-8B-Instruct-Q5_K_M.gguf`. Никакого `ollama pull`.
3. Запуск только на loopback:

```bat
llama-server.exe -m Qwen3-8B-Instruct-Q5_K_M.gguf --host 127.0.0.1 --port 8081 --jinja -c 8192 -ngl 99
```

4. Python 3.12 + `pywin32` (поставить заранее, не с PyPI в день air-gap).
5. Выделить письмо в Inbox → `python simple/mailvault_simple.py`.
6. Проверить папку Черновики. Отправляет только человек.

Скрипт: [simple/mailvault_simple.py](../simple/mailvault_simple.py). Без Outlook (проверка промпта): `--thread-json simple/sample_thread.json --print-only`.

Если Outlook спросит «разрешить доступ» — один раз Allow. Для постоянного пилота: политика объекта Outlook «программный доступ» / доверенный COM. Это проще, чем писать MAPI на C++.

## День 2 — сортировка тех же 200

Не плодите сервис. Раз в час (Планировщик заданий Windows) гоняйте тот же скрипт по непрочитанным, или выделяйте пачку руками.

Ещё проще без модели: правило Outlook «noreply@ / unsubscribe → категория FYI». LLM только на то, что правило не сняло.

## Когда усложнять

| Симптом | Следующий шаг из полной схемы |
| --- | --- |
| Каждый раз OOM Guard | MAPI sidecar |
| Черновик переписывается целиком | 14B/27B только для `needs_reply` |
| «Не в моём тоне» | 10 исходящих в промпт, не векторная БД |
| Потеря задач при закрытом Outlook | SQLite-очередь |
| ИБ требует «нет сокетов наружу» | WFP из `configs/wfp-airgap.ps1` |

## Ещё проще — если Outlook можно сменить

Thunderbird + ThunderAI + тот же `llama-server` на localhost. Это единственный путь «скачал add-on». Цена: не Outlook.

Для исходного ТЗ простой путь = **COM-скрипт + 8B + Черновики**, не продукт и не 27B.
