# Постатейный факторный анализ корректировки бюджета

Методика независимого финансово-строительного аудита объясняет прирост бюджета строительного проекта между базовой редакцией на старте финансирования и откорректированной редакцией.

Отклонение каждой статьи раскладывается на три фактора без двойного счета:

1. Инфляция относительно дефляторов, утвержденных в базовом бюджете.
2. Изменения проектной документации.
3. Иные причины, включая срок, форс-мажор, пропуски бюджета и стоимость финансирования.

Валюта расчетов — российский рубль.

- Текст методики: `docs/metodika-faktornogo-analiza-korrektirovki-byudzheta.md`
- Расчетный шаблон: `templates/postateynyy-faktornyy-analiz.xlsx`
- Сборка шаблона: `python3 templates/build_analysis_workbook.py`
