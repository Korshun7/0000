# MailVault — локальный ИИ-ассистент для Outlook без интернета

Система читает почту **классического Outlook** на компьютере пользователя, сортирует входящие, поднимает полный контекст переписки и предлагает варианты ответов. Модели крутятся только локально. У процессов ИИ **нет маршрута в интернет**: loopback, файлы, named pipes.

**Около 200 писем в день** — это лёгкая нагрузка. Узкое место не модель, а надёжный доступ к Outlook и запрет на автоотправку.

## Короткий выбор технологии

| Слой | Что ставить | Почему |
| --- | --- | --- |
| Почта | Classic Outlook + Cached Exchange + Extended MAPI | Письма уже на диске (OST). Graph/Copilot/New Outlook — облако, нельзя |
| Инференс | `llama-server` (llama.cpp), только `127.0.0.1` | Без телеметрии, GBNF, стабильный air-gap. Ollama не брать |
| Сортировка | Qwen3-8B Instruct, JSON по грамматике | Быстро, русский язык, предсказуемый JSON |
| Черновики | Qwen3.5 / Qwen3.8-27B или Qwen3-32B | Лучший открытый баланс «русский + инструкция + железо 24 ГБ» |
| Поиск по истории | BGE-M3 или Qwen3-Embedding + SQLite FTS5 | Гибридный поиск по тредам и «как я обычно отвечаю» |
| Хранение | SQLite WAL на диске пользователя | Транзакции, checksum, без сервера БД |
| Отправка | Только черновик в Outlook | Человек нажимает «Отправить». Система сама ничего не шлёт |

Полный проект: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Что умеет система

1. Забирать новые письма из локального профиля Outlook (Inbox и связанные папки).
2. Собирать тред по `ConversationIndex` / `ConversationId`, а не по теме письма.
3. Классифицировать: срочность, нужен ли ответ, тип, язык, связанные люди.
4. Раскладывать по категориям Outlook и внутренней очереди.
5. Предлагать **3 варианта ответа** с опорой на весь тред + похожие прошлые письма + стиль исходящих.
6. Класть выбранный текст в **Черновики Outlook** после правки человеком.

## Чего система принципиально не делает

- Не ходит в Microsoft Graph, Copilot, ChatGPT, Hugging Face, Ollama registry.
- Не отправляет письма сама.
- Не работает с «Новым Outlook» (это веб-клиент).
- Не читает облачные вложения «по ссылке» — только то, что уже скачано в OST/PST.

## Железо

Большая карта нужна **качеству черновика**, не потоку в 200 писем. Сортировку тянет 8B на 6–8 ГБ. Подробно: [docs/WHY_RESOURCES.md](docs/WHY_RESOURCES.md).

- **Черновики «почти как есть»:** GPU 24 ГБ (RTX 4090 / 5090 / 6000 Ada), удобно 64 ГБ RAM.
- **Пилот / только сортировка + черновик с правками:** GPU 8–16 ГБ или 8B на CPU ночью.
- Минимум без GPU: 32 ГБ RAM и ожидание минут на ответ.
