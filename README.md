# Сам в 5-й — самостоятельная подготовка к ШГН

Детская программа подготовки к поступлению в 5 класс физмат-лицеев Санкт-Петербурга (ФМЛ 366, 239, 30 и др.) по темам пособия Л. С. Михлина, которое используют на курсах «Математика ШГН» в Школе Вольфсона.

## Как открыть

Открой в браузере файл:

`kurs/index.html`

Или запусти локальный сервер:

```bash
cd kurs && python3 -m http.server 8080
```

Затем зайди на http://localhost:8080

## Что внутри

- 8 модулей по главам пособия Михлина
- объяснения «как для 10 лет»: примеры из жизни + лайфхаки
- задания «Разберём вместе» и «Попробуй сам»
- план на 12 недель
- ответы к заданиям

Ориентир по темам: пособие Л. С. Михлина «Для поступающих в 5 класс физико-математических школ».
