# BR-01 — пять палитр на один кадр

Один кадр (ТВ-стена), одна мебель, разные смыслы. Исходник — дуб + графитовая ниша стола + тёмно-тауповый шкаф.

| Код | Имя | Главный ход | Кому |
|-----|-----|-------------|------|
| A | Воздух | Шкаф в песок, ниша стола в тёплый серый | Если справа «давит» |
| B | Japandi | Орех + оливковый шкаф | Вечер, кино с кровати |
| C | Графит | Почти вся мебель тёмная | Кто любит контраст и прячет ТВ |
| D | Шалфей | Цвет только на большом шкафу | Характер без перекраски всей комнаты |
| E | Травертин | Всё тёплое и светлое | Максимум света, «отель» |

Рекомендация для этой комнаты (16 м², юг, сон + стол): **A или B**. C — только если сознательно хотите тёмную спальню. D — самый безопасный цвет. E — если исходный тёмный шкаф не нравится совсем.
