# BR-01 — Общий свет: включить у входа, выключить у тумбочек

Задача: зайти, зажечь свет у двери, дойти до кровати, погасить **не вставая**, с любой тумбочки. Утром — наоборот.

Это **одна группа света** (люстра / общий потолочный свет) и **три точки управления**: вход + северная тумба + южная тумба.

Важно: обычная схема не умеет «у двери только включить, у кровати только выключить». Каждая точка и зажигает, и гасит. Так и нужно: ночью гасите у подушки, утром зажигаете там же, у выхода гасите, если забыли.

Бра у изголовья — **отдельные**. Их не сажать на эту группу, иначе «выключить свет у кровати» погасит и чтение.

Работа по электрике — при отключённом автомате группы, сборку в щите делает электрик. Ниже — задание на разметку, кабель и смету по этой комнате.

---

## 1. Что ставим в этой комнате

| ID | Где | Что | Высота центра, мм |
|----|-----|-----|-------------------|
| SW01 | Вход, западная стена A, у двери | Одна клавиша / кнопка общего света | **900** |
| SW02 | Северная тумба, стена C | Два модуля в одной рамке: общий свет + бра севера | **750** |
| SW03 | Южная тумба, стена C | Два модуля: общий свет + бра юга | **750** |
| L01 | Потолок, южнее кровати (как на плане) | Люстра / общий свет | потолок 2740 |
| RL01 | Потолочная коробка у L01 или щит | Импульсное реле общего света | — |
| BR01 / BR02 | Стена C над тумбами | Бра чтения, каждое со своей клавишей | ~1200–1400 (низ/центр по светильнику) |

Дверь откатывается **вправо (восток)** в простенок 1890 мм. В этой стене (север B, `x = 1310…3200`) — пенал полотна. **Туда нельзя** ставить подрозетник и штробу: попадёте в кассету.

Поэтому входной выключатель — **не на северной стене справа от двери**, а на **западной стене A**, сразу у проёма (правая рука при входе в комнату).

---

## 2. Привязка точек (внутренний контур)

Нуль — юго-западный угол. Высота от **чистого пола**.

### SW01 — вход

```
стена: A (запад, x = 0)
y = 4400          # 150 мм южнее внутреннего СЗ-угла (y = 4550)
z = 900           # центр механизма
от косяка D1: через угол, не в откос
подрозетник: 1-местный
```

Полка у двери — только на стене B, глубина 250–300 мм, до `y ≈ 4250` не заступать на клавишу. Клавиша должна остаться в просвете: вошёл — нажал, не обходя шкаф.

### SW02 — северная тумба (F-07)

```
стена: C (восток, x = 3200)
y ≈ 4250          # ~150 мм севернее края матраса (край ~4107)
z = 750           # рука с подушки, не надо садиться
подрозетник: 2-местный
  левая/верхняя клавиша: общий свет (та же группа, что SW01)
  правая/нижняя: бра BR01 только этой стороны
```

Не ставить на стену B над тумбой: там пенал двери.

### SW03 — южная тумба (F-08)

```
стена: C (восток, x = 3200)
y ≈ 2450          # ~150 мм южнее края матраса (край ~2607), выше угла ниши 2165
z = 750
подрозетник: 2-местный
  клавиша 1: общий свет
  клавиша 2: бра BR02 только этой стороны
```

Не ставить на фасад купе и не в створе дверей шкафа. Точка на стене C, **севернее** угла ниши `(3200, 2165)`.

Y тумб сейчас оценочные. Перед штроблением: положить матрас на место, лечь, поднять руку — и сдвинуть `y` на 50–80 мм, если неудобно. Высоту 750 оставить: 900 у кровати заставляет приподниматься, 400 прячет клавишу за лампой на тумбе.

---

## 3. Какую схему брать

Для **трёх** точек в одной спальне лучше импульсное реле, не «два проходных + перекрёстный». Меньше путаницы в распайке, проще добавить четвёртую кнопку позже.

### Вариант A — основной: импульсное реле (рекомендуется)

В коробке у люстры (или в щите) стоит реле: импульс на катушку — свет сменил состояние.

Три кнопки (не фиксация, а «звонковые» / кнопки НО) соединяются **параллельно**. Нажал любую — люстра переключилась.

```
Щит: автомат освещения 10 А, кабель ВВГнг-LS 3×1.5
        │
        ▼
   RL01 реле у люстры
        ├──── L01 люстра (фаза с реле, N и PE из коробки)
        │
        ├──── кнопка SW01 (вход)
        ├──── кнопка SW02 клавиша «общий» (север)
        └──── кнопка SW03 клавиша «общий» (юг)
              все кнопки параллельно: один и тот же импульс
```

В каждый подрозетник кнопки: **3×1.5** (фаза-импульс, N для подсветки клавиши, PE если по проекту). Даже если подсветки не будет — ноль в коробке лучше заложить сразу.

Бра: от того же 2-местного подрозетника свой **3×1.5** на светильник, клавиша 2 — обычный выключатель (фиксация), не кнопка.

**Комплект:** реле импульсное 16 А (ABB, Schneider iTL, аналог), 3 кнопки в серии розеток комнаты, 2 одноклавишных для бра, 2 двухместные рамки у кровати, 1 одноместная у входа.

### Вариант B — классика: проходные + перекрёстный

Если реле ставить не хотите.

| Точка | Механизм |
|-------|----------|
| SW01 вход | проходной (3 клеммы) |
| SW02 север | **перекрёстный** (4 клеммы) — середина линии |
| SW03 юг | проходной |

Фаза со щита — на общий контакт SW01. Два «перекидных» (коридорных) провода: SW01 → SW02 → SW03. С общего контакта SW03 — фаза на люстру. Ноль и земля — к люстре, не через клавиши.

Между SW02 и SW03 оба на стене C: коридорные жилы можно вести **по стене C** (штроба над изголовьем), не заходя в пенал двери. От SW01 наверх в потолок и к SW02 — **по потолку**, не по северной стене B.

Диммер в эту классику не вставлять: нужны специальные проходные диммеры. Если когда-нибудь понадобится крутить яркость люстры — закладывайте вариант A или умное реле.

---

## 4. Как это работает утром и вечером

Вечер:

1. Вошли — SW01 — люстра горит.
2. Легли. Север гасит своей клавишей «общий», юг — своей. Не важно, кто нажимал у двери.
3. Чтение: клавиша бра на своей тумбе. Люстра уже может быть выключена.

Утро:

1. С подушки зажгли общий (если темно) или только бра.
2. У выхода погасили общий SW01, если он горел.

Если общий уже выключен у кровати, нажатие у двери его **включит** — поэтому у выхода смотрите на люстру, не на положение клавиши. У кнопок (вариант A) положения нет вообще — это нормально.

---

## 5. Чего не делать

- Не ставить выключатель на северную стену в зоне `x = 1310…3200` (пенал раздвижной двери).
- Не вешать единственную клавишу только у одной тумбы: второму человеку придётся перелезать.
- Не сажать бра на ту же линию, что люстра.
- Не ставить у входа двухклавишный «люстра + стол»: стол гасится отдельно, у кровати он не нужен.
- Не опускать клавиши у кровати на 900 мм «для единообразия с коридором» — до них не достать лёжа.
- Не экономить на 2-местном подрозетнике у тумб: потом вторую клавишу некуда поставить.
- Не вести кабель через направляющую купе и не крепить бра в створе дверей шкафа.

## 6. Кабель и смета по комнате (без трассы до щита)

Сечение освещения — **ВВГнг-LS 3×1.5**. Силовые розетки этой комнаты — отдельно, 3×2.5, в этот текст не входят.

| Позиция | Кол-во | Примечание |
|---------|--------|------------|
| Подрозетник 1-местный | 1 | SW01 |
| Подрозетник 2-местный | 2 | SW02, SW03 |
| Коробка распаячная потолочная | 1 | у L01, под реле |
| Реле импульсное 16 А | 1 | вариант A |
| Кнопка / клавиша «импульс» | 3 | общий свет |
| Выключатель 1-кл. обычный | 2 | бра |
| Рамка 1 пост | 1 | вход |
| Рамка 2 поста | 2 | тумбы, та же серия |
| Закладная люстры | 1 | по весу светильника |
| Кабель 3×1.5 SW01 → коробка L01 | ~6 м | подъём по A + потолок |
| Кабель 3×1.5 SW02 → коробка L01 | ~4 м | подъём по C + потолок |
| Кабель 3×1.5 SW03 → коробка L01 | ~4 м | |
| Кабель 3×1.5 коробка → L01 | ~1.5 м | |
| Кабель 3×1.5 на каждое бра | 2 × ~1.5 м | из своего подрозетника |
| Гофра / протяжка | по трассе | если потолок натяжной — до натяжки |

Длины — по комнате, без пути от квартирного щита. До щита закладывать отдельно по факту стояка.

Автомат группы освещения комнаты (или спальных световых групп): **10 А**, кабель 3×1.5. УЗО — по схеме щита квартиры.

---

## 7. Порядок работ

1. Разметить SW01 / SW02 / SW03 по координатам, **лечь на матрас** и поправить y у тумб.
2. Проверить трассу SW01: только стена A и потолок. Стена B справа от двери — запретная.
3. Штробы, подрозетники, потолочная коробка, закладная люстры.
4. Протянуть 3×1.5, подписать жилы: `SW01`, `SW02общ`, `SW03общ`, `BR01`, `BR02`, `L01`.
5. Закрыть стены, чистовая отделка.
6. Щит: автомат, сборка реле.
7. Механизмы в рамки: у тумб не перепутать клавишу общего (кнопка) и клавишу бра (фиксация).
8. Проверка: с двери зажечь → с севера погасить → с юга зажечь → с двери погасить. Затем бра по одному, люстра не должна мигать.

---

## 8. Связь с остальной электрикой комнаты

Этот блок — **только общий свет + бра**. Его не смешивать в одной рамке у входа с ТВ и столом.

Позже, отдельными линиями:

- розетки тумб (телефон, лампа, если не бра);
- стол, зона 1100 мм юга;
- ТВ на стене A;
- подсветка купе — свой выключатель или датчик в шкафу, не SW01.

Люстру оставить на диммере только если выбран умный/релейный диммер с несколькими кнопками. Обычный поворотный диммер у двери сломает управление с тумбочек.
